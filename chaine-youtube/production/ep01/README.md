# EP01 — Kit de production

Tout ce qui précède le rendu est ici. Il reste trois étapes, et elles se font hors de cet environnement :

1. **Voix** — coller les 6 blocs de `script.md` dans ElevenLabs (réglages : `../../02-identite.md`), bloc par bloc. Réécouter le bloc 6 au casque.
2. **Montage** — suivre la colonne visuelle de `script.md` : documents reconstitués, Ken Burns, un seul rouge. Découper les 3 Shorts pendant que le projet est ouvert.
3. **Mise en ligne** — copier `packaging.md` tel quel. Vérifier la case « pas conçu pour les enfants ».

Avant d'enregistrer : lever les points « À VÉRIFIER » de `recherche.md` (le script les contourne déjà, mais mieux vaut les trancher).

| Fichier | Rôle |
|---|---|
| `recherche.md` | Chaque fait avec sa source ; points à vérifier ; conformité |
| `script.md` | Narration EN minutée + plan visuel par bloc |
| `packaging.md` | Titre, miniature, description, chapitres, réglages |
| `shorts.md` | Les 3 Shorts autonomes |
